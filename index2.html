핵심 동작 원리 동적 카테고리 생성: populateCategories() 함수가 videos.json 안의 모든 category 값을 읽어와 중복을 제거한 뒤 드롭다운 항목으로 자동 등록합니다. 배열 검색 (tags.some): 사용자가 검색창에 "단풍"이라고 입력하면 제목뿐 아니라 tags 배열 안을 순회하여 해당 키워드가 포함된 영상을 함께 찾아냅니다. 비동기 이벤트: input 이벤트를 사용하여 검색어를 한 글자씩 입력할 때마다 화면이 실시간으로 고쳐집니다. 태그 버튼을 클릭했을 때 해당 태그로 즉시 검색되는 기능도 추가해 드릴까요? 예 영상 카드에 있는 #태그 뱃지를 클릭하면 해당 태그로 즉시 필터링되는 자바스크립트 이벤트를 추가해 줘. 태그 뱃지에 data-tag 속성을 부여하고, 비디오 컨테이너에 이벤트 위임(Event Delegation)을 설정하면 동적으로 생성되는 모든 태그의 클릭 이벤트를 깔끔하게 처리할 수 있습니다. 1. CSS 스타일 수정 (클릭 가능 표시) 태그에 마우스를 올렸을 때 손가락 모양 커서와 하이라이트 효과를 추가합니다. CSS .tag-badge { display: inline-block; background-color: #333; color: #aaa; font-size: 0.75rem; padding: 2px 6px; border-radius: 4px; margin-right: 4px; margin-top: 5px; cursor: pointer; /* 클릭 가능 커서 */ transition: background-color 0.2s, color 0.2s; } .tag-badge:hover { background-color: #007acc; /* 호버 시 강조 색상 */ color: #fff; } 2. 자바스크립트 수정 (index.html 스크립트) renderVideos에서 태그 생성 시 data-tag 속성을 지정하고, initArchive에서 컨테이너 클릭 이벤트를 감지하도록 추가합니다.
